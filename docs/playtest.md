# Human gameplay gate

This sheet is the condition for proceeding to a full level or final art pass. Automated probes show that several routes are mechanically reachable; they cannot answer whether the action is enjoyable.

## Session

1. Let a new player start with variant B and only the controls shown in game. Watch the first 60 seconds without coaching unless they become stuck.
2. Ask them to traverse the playground several times. Let them choose anchors and routes. Note where they stop moving, where they miss, and whether they retry voluntarily.
3. Compare A, B, and C using keys 1, 2, and 3. Use **Shift+R** to restart the timer for each variant. Rotate the order across players to reduce the advantage of learning the space.
4. Capture the player's own words immediately after attempts. Do not infer enjoyment solely from completion time.

Ask the player:

1. Did you feel responsible for where the puppet went after release?
2. When you missed, what do you think caused it?
3. Did timing a later or earlier release change the result in a way you could predict?
4. Did you feel more capable after a few attempts? What changed?
5. Did you imagine a route the game did not explicitly show you?
6. Would you repeat a swing with no reward attached? Which one?
7. Did a miss feel like “I almost had it” or did it feel frustrating? Why?

## Decision rule

Proceed only if human feedback indicates that release timing is legible, improvement is felt, and players want to retry. If players fail without understanding why, tune trajectory cues, rope behavior, and camera before adding content. If players can complete the course but avoid swinging, reconsider anchor placement and motion feel. Compare timing, route choice, downtime, and recovery as well as completion.

Record the chosen variant and specific parameter changes in `scripts/wind_puppet.gd` after the playtest. Do not treat this sheet, automated pass counts, or a designer's own expectation as a completed playtest.
