# Repository instructions

- Keep `CHANGELOG.md` current. Every change that affects gameplay, levels,
  controls, balance, content, presentation, audio, player-visible behavior, or a
  game-facing bug fix must update the **Unreleased** section in the same change.
- Preserve existing changelog history. Record removals and reversions as new
  entries instead of editing or deleting old entries.
- Remove the “No game changes yet” placeholder when adding the first Unreleased
  entry, and restore it only after those entries are moved into a dated release.
